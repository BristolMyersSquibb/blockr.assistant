# blockr.assistant: An LLM Assistant Extension for 'blockr'

Building on the docking layout manager provided by 'blockr.dock', this
extension hosts an 'ellmer'-powered chat interface alongside a 'blockr'
board. The chat is equipped with tools that allow a large language model
to inspect and manipulate board state – adding, removing and modifying
blocks, links and stacks – via the same update channel used by
interactive user actions.
